# Demo Life — the rich demo

This is the bundled rich demo repo shipped with **strictlykeptboy**.
First-launch onboarding seeds it into `filesDir/demo-repos/rich-demo/`
so a new user lands in a fully-populated schedule view without having
to author anything themselves.

## What's in here

**Calendars (11):**

- `work` — Cubicle 14, junior developer role; standup, sprint
  ceremonies, ad-hoc meetings.
- `commute` — tube + overground each weekday.
- `routines` — wake-up, teeth, dress, breakfast, wind-down, bedtime.
- `gym` — strength M/W/F + Saturday cardio.
- `kinky-rituals` — cage on/off, plug evenings, edging, Sunday journal.
- `dom-overlay` — Boy Keeper's voice on the schedule: text-owner
  prompts, check-ins, mandates.
- `social` — Daddy meet-ups, friends, queer book club.
- `cat-care` — feed Beans morning + evening, litter, vet.
- `holidays` — UK Spring bank holiday in-window.
- `vacation` — DevConf Berlin trip (days 12–15) + Brighton weekend
  (days 8–9).
- `family-visits` — Mum's Sunday brunch, Dad's birthday dinner,
  grandma's anniversary.

**Todolists (5):**

- `daily-rituals` — standing morning + evening checklists.
- `work-sprint-25` — sprint board with mixed states.
- `groceries` — flat shopping list.
- `cat-care` — Beans-care mixed dated + standing tasks.
- `owner-activity-log` — diary the AI dom (Boy Keeper) reads each
  evening; pre-seeded with 3 days of retrospective entries.
