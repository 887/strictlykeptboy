# wizard bat-mascot sticker set spec (Phase K.11 / LW-K)

This file is the artist's brief for the bat-mascot sticker set used by the
Phase K design-a-lifestyle wizard. Until the artist delivers, the app uses
`R.drawable.about_bat` as a single-sticker placeholder for every key below.

## Naming

`drawable/wiz_bat_<key>.webp`, 512x512 transparent canvas, M3E-friendly
palette aligned with the launcher icon's dark-amber-on-near-black scheme.
All stickers are the bat-mascot (the Claude-the-builder persona, per D.56);
they are NOT the user's avatar species.
